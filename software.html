Tools & Software

🧠

LASHiS — Longitudinal Automatic Segmentation of Hippocampal Subfields

Longitudinal segmentation of hippocampal subfields from multi-contrast MRI, built on ANTs.

Python ANTs 7T MRI

GitHub · Paper (NeuroImage 2020)

🧬

TongueSegMRI — Tongue Musculature Segmentation

A guide to segmenting the tongue muscles on MRI, validated in people living with MND.

Python Segmentation MND

GitHub · Paper (CIBM 2025)

📈

Neurodesk — Reproducible Neuroimaging Environment

Hundreds of neuroimaging tools in containers, so an analysis runs the same on any computer.

Containers Open Science Nature Methods

neurodesk.org · Contributors · Paper (Nature Methods 2024)

🧬

VesselBoost — Blood Vessel Segmentation

Deep-learning segmentation of small blood vessels in MR angiography.

Python Deep Learning MR Angiography

GitHub · Paper (Aperture Neuro 2024)

🧠

OSHy-X — Hypothalamic-ForniX Atlas & Segmentation

Atlases and a segmentation tool for the hypothalamus and fornix at 3T and 7T.

Python JOSS MND

GitHub · Paper (JOSS 2022)

🏹

BodyLocaliser — fMRI Body Localiser Task

A PsychoPy fMRI task that maps the body in motor cortex.

Python PsychoPy fMRI

GitHub

🎬

MRI2Vid — MRI to Video Converter

Turns a DICOM, NIfTI, or MGZ scan into a scrolling video in your browser. Images never leave your computer.

Browser DICOM NIfTI Utility

Open the tool · GitHub
